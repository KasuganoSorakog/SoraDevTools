# Markdown 语法指南

## 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

---

## 文本格式

```markdown
**粗体文本**
__也是粗体__

*斜体文本*
_也是斜体_

***粗斜体***

~~删除线~~

`行内代码`
```

效果：**粗体** | *斜体* | ***粗斜体*** | ~~删除线~~ | `行内代码`

---

## 段落与换行

```markdown
段落之间用空行分隔。

这是第二段。

行尾加两个空格
可以在段落内换行。
```

---

## 列表

```markdown
<!-- 无序列表 -->
- 项目一
- 项目二
  - 子项目（缩进2空格）
  - 子项目
* 也可以用星号
+ 也可以用加号

<!-- 有序列表 -->
1. 第一项
2. 第二项
3. 第三项

<!-- 任务列表（GitHub风格） -->
- [x] 已完成
- [ ] 未完成
- [ ] 待处理
```

---

## 链接与图片

```markdown
<!-- 链接 -->
[链接文字](https://example.com)
[带标题的链接](https://example.com "鼠标悬停提示")

<!-- 引用式链接 -->
[链接文字][ref]
[ref]: https://example.com

<!-- 图片 -->
![替代文字](image.png)
![替代文字](image.png "图片标题")
```

---

## 引用块

```markdown
> 这是一段引用文本。
>
> 引用可以包含多段。
>
>> 嵌套引用
```

效果：
> 这是引用文本。
>> 嵌套引用

---

## 代码块

````markdown
<!-- 行内代码 -->
使用 `console.log()` 打印日志。

<!-- 围栏代码块（指定语言可语法高亮） -->
```python
def hello():
    print("Hello, World!")
```

```csharp
public class Example {
    void Start() { }
}
```
````

## 表格

```markdown
| 列1     | 列2     | 列3     |
|---------|:-------:|--------:|
| 默认左对齐 | 居中    | 右对齐  |
| 数据    | 数据    | 数据    |
| 数据    | 数据    | 数据    |
```

效果：

| 列1 | 列2 | 列3 |
|-----|:---:|----:|
| 左对齐 | 居中 | 右对齐 |
| 数据 | 数据 | 数据 |

---

## 分隔线

```markdown
---
***
___
```

---

## 转义字符

在特殊字符前加 `\` 可以转义：

```markdown
\*不是斜体\*
\# 不是标题
\[不是链接\]
```

可转义字符：`\` `` ` `` `*` `_` `{}` `[]` `()` `#` `+` `-` `.` `!`

---

## HTML 内嵌

Markdown 支持直接嵌入 HTML：

```markdown
<div style="color: red;">红色文字</div>
<br> <!-- 换行 -->
<details>
  <summary>点击展开</summary>
  折叠内容
</details>
```

---

## 脚注（部分渲染器支持）

```markdown
这里有一个脚注[^1]。

[^1]: 这是脚注内容。
```

## 数学公式（部分渲染器支持）

```markdown
行内公式：$E = mc^2$

块级公式：
$$
\sum_{i=1}^{n} x_i = x_1 + x_2 + \cdots + x_n
$$
```

## 最佳实践

1. 标题 `#` 后面加一个空格
2. 列表项 `-` 后面加一个空格
3. 代码块始终标注语言名称（便于语法高亮）
4. 段落之间保留一个空行
5. 文件末尾保留一个换行符
